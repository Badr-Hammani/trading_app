# Project Rules & Directives for Antigravity

## 📸 Mandatory Visual Verification & Screenshot Proof
- **NEVER declare a UI, chart, canvas overlay, or visual feature fix/change complete** based solely on code edits, unit tests, or typechecks.
- **ALWAYS capture empirical visual screenshot proof** of the live running application (e.g. `http://localhost:3000`) using Chrome headless or browser verification tools.
- **ALWAYS embed the verified screenshot image directly in your response** to the user using standard markdown image syntax (`![caption](absolute_path)`).
- If a visual verification fails or shows an unexpected UI error, fix the root cause first before reporting success to the user.
